# AGP轨迹回放

6个任务、12条轨迹、36段相机录像。比较 **AGP完整提示版** 与 **AGP去除资产描述版**。

页面支持任务和相机选择、双视频播放、中文过程概览、逐次调用阅读，以及展开原始英文、动作参数与执行回执。

去除版仅删除明确的任务资产描述，仍保留任务规则与操作建议。两版政策、数学工具和控制逻辑相同。每项一个相同布局、seed 0；仅作描述性对照。分数来自原生环境，模型自评不作为得分。公开计划陈述可能与实际物理状态不同；没有可读的内部思考记录，页面不补写内部推理。

这是静态展示网站，不包含模型调用、账号凭据或实验控制服务。可通过 GitHub Pages 发布；也可下载仓库后双击 `打开回放.html` 离线浏览。
